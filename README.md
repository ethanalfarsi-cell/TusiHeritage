# Xiangxi Fu Official Website

A Next.js + TypeScript + Tailwind CSS website for Xiangxi Fu, inspired by the clear museum-style structure of Rijksmuseum while using Xiangxi Fu content, imagery and brand language.

## Run locally

Standard Node.js workflow:

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`, or run `dev.cmd` to use `http://127.0.0.1:3011`.

This workstation currently has a local dependency copy and Adobe Node runtime available, so you can also double-click or run:

```bat
dev.cmd
build.cmd
```

The current preview server for this workspace is running at `http://127.0.0.1:3011`.

## Main editable configuration

- `data/siteConfig.ts`
- `data/contact.ts`
- `data/attractions.ts`
